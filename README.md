# 全嘉包裝有限公司 — 官網

一頁式靜態網站，純 HTML/CSS，沒有建構工具或框架依賴。

## 本機預覽

直接用瀏覽器打開 `index.html`，或起一個簡單的本機伺服器：

```bash
python3 -m http.server 8000
```

再打開 `http://localhost:8000`。

## 待確認事項

網頁上以橘色虛線標籤標示的地方，正式上線前需要補上：

- 聯絡電話
- 公司網域信箱
- 地址
- 營業時間

另外「客製化印刷」段落目前假設是全嘉自己接洽印刷廠協調，如果實際上是委外印刷廠代工，文案需要再調整措辭。

## 部署

純靜態網站，可以直接部署到 GitHub Pages、Netlify、Vercel 或任何靜態網站空間，不需要伺服器端程式。
